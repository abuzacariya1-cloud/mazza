# MAZZA — чайхана · кафе

Сайт кафе MAZZA: восточная кухня халяль, Санкт-Петербург, Ручьёвская дорога, 16. Телефон: +7 952 260-48-48. Работаем ежедневно с 10:00 до 00:00.

Сайт состоит из страницы `index.html` и папки `img` с фото. Фото подгружаются по мере прокрутки. Заказы и брони отправляются в Telegram через Cloudflare Worker `mazza-notify`.

На сайте четыре страницы:

- главная;
- меню с составом блюд;
- заказ, доставка и самовывоз;
- бронь столов и банкеты.

Часть фото блюд и все фото ингредиентов взяты с Unsplash. Их можно использовать бесплатно, в том числе в коммерческих целях: https://unsplash.com/license

Остальные фото блюд и фото зала взяты из карточки кафе на Яндекс Картах. Их со временем стоит заменить собственной съёмкой.
